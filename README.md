# Pizzería de muestra

Sitio de muestra de una pizzería: una pizza 3D hecha con fotos por capas que se desarma mientras se baja,
con paneles de información, carta con precios y pedido. Es una plantilla de demostración, sin datos de un negocio real.

Hecho con HTML, CSS y JavaScript, y GSAP + ScrollTrigger para la animación.
